# SHAP 분석 결과

튜닝된 XGBoost 모델의 test set 예측을 변수별 기여도로 분해했다.
`temp`는 `atemp`와 상관 0.9917로 중복이라 입력에서 제외되어 있다(common.py 참고).

두 방식의 순위 차이는 평균 1.8계단, 최대 3계단이다. SHAP은 "평균 예측에서 실제로 몇 건을 밀어올렸/내렸는가"를 건수 단위로 재므로, 트리 내부의 분기 이득을 세는 gain보다 해석이 직관적이다.

## SHAP이 추가로 알려주는 것

gain 중요도는 크기만 알려주지만, SHAP은 **방향과 형태**를 보여준다.

- `outputs/model/shap_beeswarm.png`: 변수별로 점 하나가 하루를 뜻한다. 점이 오른쪽에 있으면 그날 예측을 끌어올린 것이고, 색이 붉을수록 그 변수의 값이 높다. 따라서 "값이 높을 때 수요가 오르는지 내리는지"를 한눈에 볼 수 있다.
- `outputs/model/shap_dependence_atemp.png`: 체감온도가 올라갈수록 기여가 어떻게 변하는지 곡선으로 보여준다. 선형회귀 계수 하나로는 표현할 수 없는 비선형 구간을 확인할 수 있다.

## 변수값과 기여도의 방향

| 변수 | 상관(변수값 vs SHAP) | 해석 |
|---|---|---|
| yr(연도) | — | 테스트 구간에서 값이 고정(1)되어 판정 불가 |
| atemp(체감온도) | +0.939 | 값이 클수록 대여량 증가 |
| season(계절) | +0.879 | 값이 클수록 대여량 증가 |
| hum(습도) | -0.856 | 값이 클수록 대여량 감소 |
| windspeed(풍속) | -0.874 | 값이 클수록 대여량 감소 |
| weathersit(날씨등급) | -0.955 | 값이 클수록 대여량 감소 |

- 상관이 0에 가까우면 단조 관계가 아니라 구간별로 방향이 바뀐다는 뜻이므로, 위 의존성 플롯을 함께 봐야 한다.
- `yr`은 테스트 구간(2012년 하반기)에서 값이 1로 고정되어 있어 방향을 잴 수 없다. 이는 5절에서 다룬 "yr은 학습 기간 안에서만 유효한 변수"라는 한계와 같은 맥락이다.
