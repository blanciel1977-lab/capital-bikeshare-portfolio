# yr 변수 제거 + detrend 분석
## 배경
`yr`은 2011/2012 두 범주뿐인 이진 변수이며, 튜닝 모델에서 중요도 34%로 1위였다. 이는 "날씨/계절의 진짜 효과"가 아니라 "그 2년간 서비스가 이만큼 성장했다"는 사실을 암기한 결과로, 미래 연도(2013년 이후)에는 재사용할 수 없다.

## 보정 방법
`cnt_relative = cnt / (해당 연도 평균 cnt)` 로 변환해 "그 해 평균 대비 몇 배인가"라는 상대지수를 목표변수로 삼고, `yr`을 입력에서 제외한 뒤 날씨/계절/요일 변수로 재학습한다.

## 성능 (상대지수 단위, 절대치 모델과 직접 비교 불가)
- RMSE: 0.1623
- MAE: 0.1162
- R2: 0.7815

## 실무 적용: 2단계 예측 파이프라인
1. 연도별 기준선(baseline) 추정 - 과거 성장 추세(예: 2011->2012 +64%) 또는 등록회원 증가율 등 외부 지표로 미래 연도의 평균 대여량 추정
2. 이 모델로 날씨/계절/요일 조건에 따른 "기준선 대비 상대지수" 예측
3. 최종 예측 = 1의 기준선 x 2의 상대지수
